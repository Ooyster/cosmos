# Cosmos Transfer - Standalone Version

## 📖 Introduction
The original **Cosmos Transfer** operated on a Client-Server architecture. This project refactors it into a **standalone, directly executable version**.

## ✨ Optimize Innovation
* **Simplified Architecture**: Converted from Client-Server to a direct execution model.
* **Portable Deployment**: Supports a "Build Once, Run Anywhere" workflow.The Docker image can be deployed across different machines instantly without the need for redeployment or environment reconfiguration.
* **Enhanced Pipeline Flexibility**: Key files are mounted externally, offering a higher degree of freedom to modify the pipeline logic.
* **Extensive input and output options**：Now outputs frame-by-frame images and preprocessed video in addition to the original video input and output, facilitating direct integration into algorithms such as autonomous driving testing.
